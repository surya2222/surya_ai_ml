Chapter 1: Introduction (परिचय)

अध्याय 1

1.1 What is Jupyter Notebook? (जुपिटर नोटबुक क्या है?)

Jupyter Notebook एक ओपन-सोर्स (Open-Source), वेब-आधारित इंटरैक्टिव कम्प्यूटेशनल वातावरण (Web-based Interactive Computing Platform) है। यह प्रोग्रामर्स, डेटा साइंटिस्ट्स और रिसर्चर्स को लाइव कोड लिखने, उसे तुरंत रन करने, गणितीय समीकरण (Equations), विज़ुअलाइज़ेशन (Charts/Graphs) और विवरणात्मक टेक्स्ट (Narrative Text / Markdown) को एक ही दस्तावेज़ में संकलित करने की सुविधा प्रदान करता है।

नामकरण का इतिहास: "Jupyter" नाम तीन मुख्य वैज्ञानिक प्रोग्रामिंग भाषाओं के संयोजन से बना है:

  • Ju: Julia (जूलिया)
  • Py: Python (पायथन)
  • R: R लैंग्वेज (सांख्यिकी के लिए)

हालाँकि यह प्रोजेक्ट मूल रूप से 2014 में Fernando Pérez द्वारा IPython से अलग होकर Project Jupyter के रूप में विकसित हुआ था और आज यह 40 से अधिक प्रोग्रामिंग भाषाओं का समर्थन करता है।

1.2 Features of Jupyter Notebook (मुख्य विशेषताएँ)

  • इंटरैक्टिव एक्ज़ीक्यूशन (Interactive Execution): पूरे प्रोग्राम को एक साथ रन करने के बजाय कोड को छोटे-छोटे टुकड़ों (Cells) में रन किया जा सकता है और आउटपुट तुरंत सेल के नीचे दिखाई देता है।
  • रिच मीडिया व विज़ुअलाइज़ेशन सपोर्ट (Rich Media Integration): Matplotlib, Seaborn, Plotly आदि के माध्यम से बनाए गए चार्ट, इमेज, वीडियो और HTML टेबल सीधे नोटबुक के अंदर एम्बेड हो जाते हैं।
  • मार्कडाउन व LaTeX सपोर्ट (Markdown & LaTeX): तकनीकी प्रलेखन (Technical Documentation) और जटिल गणितीय सूत्रों को स्पष्ट रूप से लिखने के लिए Markdown तथा MathJax/LaTeX का सहज समर्थन।
  • मल्टी-लैंग्वेज सपोर्ट (Kernels): विभिन्न भाषाओं के लिए कर्नल उपलब्ध हैं (Python, R, Julia, Scala, C++, आदि)।
  • शेयरेबल और पोर्टेबल (Shareable): नोटबुक फ़ाइलों को .ipynb, PDF, HTML, Python Script, या Markdown फ़ाइलों के रूप में आसानी से शेयर किया जा सकता है। GitHub सीधे .ipynb फ़ाइलों को रेंडर करता है।

1.3 Uses & Applications (उपयोग व अनुप्रयोग)

  • डेटा क्लीनिंग और ट्रांसफॉर्मेशन (Data Cleaning & Wrangling): असंरचित डेटा को लोड करना, मिसिंग वैल्यूज भरना, और डेटा की रीशेपिंग करना।
  • डेटा विज़ुअलाइज़ेशन (Exploratory Data Analysis - EDA): डेटा के पैटर्न, आउटलायर्स (Outliers) और डिस्ट्रीब्यूशन को ग्राफ्स द्वारा समझना।
  • मशीन लर्निंग और डीप लर्निंग (ML & DL Modeling): Scikit-Learn, TensorFlow, PyTorch का उपयोग करके मॉडल्स को स्टेप-बाय-स्टेप ट्रेन और ट्यून करना।
  • वैज्ञानिक कंप्यूटिंग व अनुसंधान (Scientific Research): प्रयोगों के परिणाम, कोड और निष्कर्षों का एक रीप्रॉड्यूसिबल (Reproducible) रिकॉर्ड तैयार करना।
  • शैक्षणिक उद्देश्य (Teaching & Learning): कोडिंग ट्यूटोरियल, इंटरैक्टिव बुक्स और प्रैक्टिकल नोट्स बनाना।

1.4 Jupyter Notebook vs Traditional Python IDE

अक्सर शुरुआती छात्रों में यह संशय होता है कि क्या Jupyter एक IDE (जैसे VS Code, PyCharm) का विकल्प है? आइए नीचे दी गई तुलना से समझें:

विशेषता (Feature) Jupyter Notebook Traditional IDE (VS Code, PyCharm)
कोड निष्पादन (Execution) सेल-दर-सेल (Cell-by-Cell) इंटरैक्टिव निष्पादन। संपूर्ण स्क्रिप्ट या मॉड्यूल एक साथ रन होता है।
डेटा पर्सिस्टेंस (State in Memory) एक सेल रन होने के बाद वैरिएबल्स मेमोरी में सुरक्षित रहते हैं। बार-बार डेटा लोड करने की आवश्यकता नहीं होती। स्क्रिप्ट खत्म होते ही मेमोरी खाली हो जाती है (जब तक कि डीबगर न लगा हो)।
डेटा विज़ुअलाइज़ेशन ग्राफ और चार्ट्स सीधे कोड के नीचे इनलाइन दिखते हैं। चार्ट्स अलग विंडो (Pop-up GUI) में खुलते हैं।
दस्तावेज़ीकरण (Documentation) कोड के साथ-साथ समृद्ध टेक्स्ट, हेडिंग और इमेज एम्बेड होते हैं। केवल कोड कमेंट्स (# या docstrings) का सहारा होता है।
डीबगिंग व रिफैक्टरिंग बेसिक डीबगिंग (pdb/IPython) संभव है, लेकिन जटिल प्रोजेक्ट रिफैक्टरिंग सीमित है। शक्तिशाली डीबगर, ब्रेकपॉइंट्स, लिंटर्स और गिट इंटीग्रेशन।
सर्वश्रेष्ठ उपयोग (Best For) डेटा एक्सप्लोरेशन, प्रोटोटाइपिंग, मशीन लर्निंग, एनालिसिस। फुल-स्टैक सॉफ्टवेयर डेवलपमेंट, वेब ऐप्स (Django/Flask), लार्ज कोडबेस।
💡
गोल्डन टिप:

डेटा एनालिसिस, रिसर्च और मॉडल एक्सप्लोरेशन के लिए Jupyter Notebook सर्वोत्तम है, जबकि प्रोडक्शन-रेडी सॉफ्टवेयर और APIs बनाने के लिए VS Code या PyCharm सबसे उपयुक्त हैं।

Chapter 2: Installation (इन्स्टॉलेशन)

अध्याय 2

Jupyter Notebook को इंस्टॉल करने के मुख्य रूप से दो तरीके हैं: pip (Python Package Manager) के माध्यम से या Anaconda Distribution के माध्यम से।

2.1 Python Installation (पायथन की स्थापना)

यदि आपके सिस्टम में पायथन नहीं है, तो सबसे पहले पायथन इंस्टॉल करें:

  1. आधिकारिक वेबसाइट python.org पर जाएं।
  2. Windows / macOS के लिए नवीनतम Python 3.x इंस्टॉलर डाउनलोड करें।
  3. महत्वपूर्ण चरण: इंस्टॉलर खोलते ही सबसे नीचे दिए गए चेकबॉक्स ☑ Add python.exe to PATH को अवश्य टिक करें।
  4. "Install Now" पर क्लिक करें।
  5. कमांड प्रॉम्प्ट (CMD) खोलकर पुष्टि करें: 
    python --version
pip --version

2.2 pip द्वारा Jupyter Notebook इंस्टॉल करना

यदि आपके पास शुद्ध पायथन (Vanilla Python) पहले से मौजूद है, तो टर्मिनल या कमांड प्रॉम्प्ट में निम्न कमांड चलाएं:

# pip को अपडेट करें
python -m pip install --upgrade pip

# क्लासिक Jupyter Notebook इंस्टॉल करें
pip install notebook

# या आधुनिक JupyterLab इंस्टॉल करें (वैकल्पिक)
pip install jupyterlab

2.3 Anaconda Distribution द्वारा इंस्टॉलेशन (अनुशंसित / Recommended)

Anaconda क्या है? यह डेटा साइंस और मशीन लर्निंग के लिए दुनिया का सबसे लोकप्रिय प्लेटफॉर्म है। इसमें Python, Jupyter Notebook, JupyterLab, Spyder, और 1500+ महत्वपूर्ण साइंटिफिक लाइब्रेरीज़ (NumPy, Pandas, Matplotlib, Scikit-Learn आदि) पहले से इंस्टॉल मिलती हैं।

Anaconda इंस्टॉलेशन के चरण:

  1. anaconda.com पर जाएं और "Download Anaconda Distribution" पर क्लिक करें।
  2. इंस्टॉलर चलाएं और डिफ़ॉल्ट सेटिंग्स के साथ Next-Next करते हुए इंस्टॉल पूरा करें।
  3. इंस्टॉल होने के बाद आपके स्टार्ट मेनू में Anaconda Navigator और Anaconda Prompt उपलब्ध हो जाएंगे।
पैरामीटर pip विधि (Lightweight) Anaconda विधि (All-in-One)
डाउनलोड साइज छोटा (~100 MB केवल पायथन + जुपिटर) बड़ा (~600 MB - 1 GB पूरा डेटा साइंस पैकेज)
डिपेंडेंसी हैंडलिंग प्रत्येक पैकेज (pandas, sklearn) अलग से pip install करना होगा लगभग सभी जरूरी पैकेजेस पहले से शामिल रहते हैं
एनवायरनमेंट मैनेजमेंट venv / virtualenv conda (Conda Environments)

2.4 इंस्टॉलेशन की पुष्टि (Verification)

अपने टर्मिनल में निम्न कमांड टाइप करके देखें कि क्या जुपिटर सही से इंस्टॉल हो गया है:

jupyter --version

यह आपके सिस्टम में इंस्टॉल IPython, notebook, और jupyter_core के वर्ज़न प्रदर्शित करेगा।

Chapter 3: Launching (लॉन्च करना)

अध्याय 3

3.1 Start Notebook (नोटबुक शुरू करना)

Jupyter Notebook को शुरू करने के तीन सामान्य तरीके हैं:

विधि 1: Command Prompt / Terminal द्वारा (सर्वश्रेष्ठ तरीका)

जिस फ़ोल्डर में आप अपना काम या प्रोजेक्ट सेव करना चाहते हैं, टर्मिनल में उस फ़ोल्डर तक जाएं:

# अपने प्रोजेक्ट फ़ोल्डर में जाएं
cd "C:\Users\M_SURYA\Desktop\jupyter notebook"

# जुपिटर नोटबुक सर्वर प्रारंभ करें
jupyter notebook

विधि 2: Anaconda Prompt द्वारा

विंडोज़ स्टार्ट मेन्यू से Anaconda Prompt खोलें और टाइप करें: jupyter notebook

विधि 3: Anaconda Navigator (GUI) द्वारा

Anaconda Navigator ऐप खोलें और होम स्क्रीन पर Jupyter Notebook टाइल के नीचे "Launch" बटन पर क्लिक करें।

3.2 Browser Interface (वेब ब्राउज़र इंटरफ़ेस)

जैसे ही आप कमांड चलाते हैं, जुपिटर आपके डिफ़ॉल्ट वेब ब्राउज़र (Chrome, Edge, Firefox) में एक नया टैब खोलता है।

  • डिफ़ॉल्ट यूआरएल: http://localhost:8888/tree
  • यदि ऑटोमैटिकली ब्राउज़र न खुले, तो टर्मिनल में प्रिंट हुए टोकन वाले लिंक (उदा. http://127.0.0.1:8888/?token=abcdef...) को कॉपी करके किसी भी ब्राउज़र में पेस्ट कर सकते हैं।

3.3 Local Server Concept (लोकल सर्वर सिद्धांत)

यह समझना अत्यंत महत्वपूर्ण है कि जुपिटर नोटबुक क्लाउड पर नहीं, बल्कि आपकी अपनी मशीन पर चलता है:

टर्मिनल (CLI)
Background Python Server
⇄
Localhost:8888
HTTP Protocol / Sockets
⇄
वेब ब्राउज़र
User Frontend Interface
  • Localhost (127.0.0.1): इसका अर्थ है कि सर्वर आपके ही कंप्यूटर के आंतरिक नेटवर्क लूप पर सुन रहा है।
  • Port 8888: यह वह नेटवर्क पोर्ट है जिस पर जुपिटर संचार करता है। यदि 8888 पोर्ट व्यस्त हो, तो यह स्वतः 8889 या 8890 चुन लेता है।
  • टर्मिनल बंद न करें: जब तक आप नोटबुक में काम कर रहे हैं, उस ब्लैक टर्मिनल विंडो को बंद न करें! वह बैकएंड इंजन है। यदि आपने वह विंडो बंद कर दी, तो सर्वर क्रैश हो जाएगा और नोटबुक रिस्पॉन्स देना बंद कर देगी।
  • सर्वर को बंद करने का सही तरीका: टर्मिनल में जाकर दो बार Ctrl + C दबाएं।

Chapter 4: Interface (इंटरफ़ेस)

अध्याय 4

4.1 Dashboard (डैशबोर्ड / Tree View)

ब्राउज़र खुलते ही जो पहला पेज दिखाई देता है, उसे Jupyter Dashboard कहते हैं। इसमें मुख्य रूप से तीन टैब होते हैं:

  • Files Tab: आपकी वर्तमान डायरेक्टरी की सभी फ़ाइलें और सब-फ़ोल्डर्स दिखाता है। यहाँ से आप फ़ाइलों को खोल सकते हैं, डिलीट कर सकते हैं या मूव कर सकते हैं।
  • Running Tab: यह दिखाता है कि इस समय बैकग्राउंड में कौन-कौन से नोटबुक्स और कर्नल्स सक्रिय (Active) हैं। यदि सिस्टम स्लो हो जाए, तो यहाँ से निष्क्रिय कर्नल्स को Shutdown किया जा सकता है।
  • Clusters Tab: IPython Parallel कंप्यूटिंग के लिए उपयोग होता है (सामान्य उपयोगकर्ताओं के लिए यह कम उपयोग में आता है)।

4.2 Notebook View Components (नोटबुक दृश्य के घटक)

जब आप कोई नोटबुक (.ipynb) खोलते हैं, तो इंटरफ़ेस 5 मुख्य भागों में विभाजित होता है:

  1. Header (शीर्षक क्षेत्र):
    • Jupyter लोगो और नोटबुक का नाम (डिफ़ॉल्ट रूप से Untitled)। नाम पर क्लिक करके इसे कभी भी रीनेम किया जा सकता है।
    • लास्ट सेव चेकपॉइंट (Last Checkpoint status) का समय प्रदर्शित होता है।
  2. Menu Bar (मेनू बार): विभिन्न ऑपरेशन्स के लिए ड्रॉप-डाउन मेनू (File, Edit, View, Insert, Cell, Kernel, Widgets, Help)।
  3. Toolbar (टूलबार): सामान्य कार्यों के लिए एक-क्लिक शॉर्टकट आइकन्स (Save, Add cell, Cut, Copy, Paste, Move up/down, Run, Stop, Restart, Cell-type dropdown)।
  4. Notebook Canvas / Cells Area: मुख्य कार्यक्षेत्र जहाँ कोड लिखा और आउटपुट देखा जाता है।
  5. Status / Kernel Indicator: ऊपर दाईं ओर एक छोटा वृत्त (Circle) दिखता है:
    • ⭕ Empty Circle: Kernel Idle (कर्नल खाली है और इनपुट के लिए तैयार है)।
    • ⚫ Filled Circle: Kernel Busy (कर्नल कोड निष्पादित कर रहा है)।

Chapter 5: Creating & Managing Notebook (नोटबुक निर्माण एवं प्रबंधन)

अध्याय 5

5.1 Create New Notebook (नई नोटबुक बनाना)

  1. Jupyter Dashboard (फ़ाइल ब्राउज़र) में जाएं।
  2. ऊपर दाईं ओर स्थित "New" ड्रॉपडाउन बटन पर क्लिक करें।
  3. Notebook सेक्शन के अंतर्गत "Python 3 (ipykernel)" चुनें।
  4. एक नया ब्राउज़र टैब खुलेगा जिसमें एक खाली कोड सेल के साथ एक नई नोटबुक तैयार होगी।

5.2 Rename Notebook (नोटबुक का नाम बदलना)

  • तरीका 1: हेडर में सबसे ऊपर लिखे नाम (उदा. Untitled) पर सीधे क्लिक करें। एक पॉप-अप डायलॉग बॉक्स खुलेगा, उसमें नया नाम लिखें और Rename दबाएं।
  • तरीका 2: मेनू बार से File -> Rename... पर जाएं।

5.3 Save and Checkpoints (सुरक्षित करना और चेकपॉइंट्स)

Jupyter Notebook में ऑटोसेव (Auto-save) सुविधा होती है, जो हर 2 मिनट में आपकी प्रोग्रेस को स्वतः सेव करती है। इसके अलावा Checkpoints की एक शक्तिशाली प्रणाली होती है:

  • Manual Save: Ctrl + S दबाने पर एक विशेष Checkpoint बन जाता है।
  • चेकपॉइंट क्या है? यह आपकी नोटबुक की स्थिति का एक स्नैपशॉट है जो .ipynb_checkpoints नाम के एक गुप्त फ़ोल्डर में सहेजा जाता है।
  • Revert to Checkpoint: यदि कोड में कोई बड़ी गलती हो जाए, तो आप File -> Revert to Checkpoint पर जाकर पिछली सुरक्षित स्थिति में वापस लौट सकते हैं।

5.4 Download Options (नोटबुक डाउनलोड/निर्यात करना)

अपनी नोटबुक को अन्य प्रारूपों में निर्यात करने के लिए File -> Download as पर जाएं:

  • Notebook (.ipynb): पूर्ण इंटरैक्टिव नोटबुक फ़ाइल।
  • Python (.py): सभी कोड सेल्स को मिलाकर एक स्टैंडर्ड पायथन स्क्रिप्ट बनाता है (मार्कडाउन को कमेंट # में बदल देता है)।
  • HTML (.html): एक स्टैंडअलोन वेबपेज जिसमें आउटपुट और चार्ट्स शामिल होते हैं (क्लाइंट्स या टीम को बिना जुपिटर के रिपोर्ट भेजने के लिए सर्वोत्तम)।
  • PDF via LaTeX (.pdf): प्रिंट करने योग्य डॉक्यूमेंट। (इसके लिए सिस्टम में MikTeX/TeXLive आवश्यक है)।
  • Markdown (.md): GitHub README या ब्लॉग्स के लिए उपयुक्त।

5.5 Upload Files & Notebooks (अपलोड करना)

  1. डैशबोर्ड पर ऊपर दाईं ओर "Upload" बटन पर क्लिक करें।
  2. अपने कंप्यूटर से कोई भी .ipynb फ़ाइल, CSV डेटासेट या इमेज चुनें।
  3. फ़ाइल लिस्ट में आने के बाद नीले रंग के "Upload" बटन पर क्लिक करके अपलोड पूरा करें।

Chapter 6: Notebook Cells (नोटबुक सेल्स)

अध्याय 6

Jupyter Notebook की आधारशिला Cells (कोशिकाएँ/ब्लॉक्स) हैं। नोटबुक दस्तावेज़ इन्हीं अलग-अलग सेल्स का संग्रह होता है। सेल मुख्य रूप से तीन प्रकार के होते हैं:

6.1 Code Cell (कोड सेल)

यह डिफ़ॉल्ट सेल प्रकार है। इसमें आप निष्पादन योग्य (Executable) पायथन कोड लिखते हैं।

  • जब सेल रन होता है, तो उसका इनपुट लेबल In [n]: बन जाता है, जहाँ n निष्पादन क्रम (Execution count) है।
  • यदि कोड कोई परिणाम प्रिंट करता है या कोई मान लौटाता है, तो वह ठीक नीचे Out [n]: में प्रदर्शित होता है।
# यह एक कोड सेल का उदाहरण है
import numpy as np
arr = np.array([10, 20, 30, 40])
print("Array Sum:", arr.sum())
arr * 2

6.2 Markdown Cell (मार्कडाउन सेल)

मार्कडाउन सेल्स का उपयोग टेक्स्ट, हेडिंग्स, व्याख्या, इमेज और गणितीय समीकरणों को सुंदर रूप में प्रस्तुत करने के लिए किया जाता है। सेल टाइप को मार्कडाउन में बदलने के लिए कमांड मोड में M दबाएं।

एलिमेंट मार्कडाउन सिंटैक्स (Markdown Syntax) रेंडर होने पर आउटपुट
Headings # H1 Heading
## H2 Heading
### H3 Heading		 शीर्षक और उप-शीर्षक (आकार के अनुसार घटते क्रम में)
Bold & Italic **मोटा (Bold)** और *तिरछा (Italic)* मोटा (Bold) और तिरछा (Italic)
Bullet List - Item 1
- Item 2		 • Item 1
• Item 2
Numbered List 1. First
2. Second		 1. First
2. Second
Hyperlink [Google Link](https://google.com) क्लिक करने योग्य लिंक
Image ![Alt Text](image_url_or_path.png) एम्बेडेड छवि (Embedded Image)
LaTeX Math $E = mc^2$ (Inline)
$$\sigma = \sqrt{\frac{\sum (x - \mu)^2}{N}}$$ (Block)		 सुंदर गणितीय सूत्र (MathJax द्वारा रेंडर)

6.3 Raw Cell (Raw NBConvert Cell)

रॉ सेल्स में लिखा गया टेक्स्ट कर्नल द्वारा निष्पादित नहीं किया जाता है और न ही मार्कडाउन की तरह रेंडर होता है। यह टेक्स्ट जैसा लिखा है, हूबहू वैसा ही आउटपुट में रहता है।

  • उपयोग: जब आप nbconvert कमांड-लाइन टूल का उपयोग करके नोटबुक को LaTeX या HTML में बदल रहे हों, तो विशेष कंपाइलर निर्देशों (Directives) को पास करने के लिए Raw Cells का उपयोग होता है।
  • शॉर्टकट: कमांड मोड में R दबाएं।

Chapter 7: Cell Execution (सेल निष्पादन)

अध्याय 7

7.1 Running Cells (सेल चलाने के विकल्प)

Jupyter Notebook में किसी सेल को निष्पादित करने के लिए विभिन्न कीबोर्ड शॉर्टकट्स और मेनू ऑप्शन्स उपलब्ध हैं:

शॉर्टकट क्रिया (Action) व्यवहार (Behavior)
Shift + Enter Run and Advance वर्तमान सेल को रन करता है और अगले सेल को सेलेक्ट करता है। यदि नीचे कोई सेल नहीं है, तो एक नया खाली सेल जोड़ देता है। (सर्वाधिक प्रयुक्त)
Ctrl + Enter Run In-Place वर्तमान सेल को रन करता है और कर्सर/फ़ोकस उसी सेल में बनाए रखता है। (क्विक टेस्टिंग के लिए बेस्ट)
Alt + Enter Run and Insert Below वर्तमान सेल को रन करता है और ठीक नीचे तुरंत एक नया खाली कोड सेल इंसर्ट कर देता है।

7.2 Global Execution Commands (एक साथ चलाना)

मेनू बार में Cell मेनू के तहत निम्न शक्तिशाली विकल्प मिलते हैं:

  • Run All: ऊपर से नीचे तक नोटबुक के सभी सेल्स को क्रमानुसार चलाता है।
  • Run All Above: वर्तमान सेल से ऊपर के सभी सेल्स को चलाता है। यह तब बहुत काम आता है जब आप बीच के किसी सेल पर काम कर रहे हों और पहले के सभी वैरिएबल्स को री-लोड करना हो।
  • Run All Below: वर्तमान सेल से लेकर अंत तक के सभी सेल्स को निष्पादित करता है।

7.3 Interrupting the Kernel (निष्पादन बीच में रोकना)

कई बार कोड में कोई Infinite Loop (जैसे while True:) बन जाता है या कोई बड़ा डेटासेट लोड होने में बहुत समय लेता है और नोटबुक हैंग हो जाती है।

  • ऐसी स्थिति में टूलबार में स्थित काले चौकोर Stop Icon (■) पर क्लिक करें या Kernel -> Interrupt चुनें।
  • कीबोर्ड शॉर्टकट: कमांड मोड में दो बार I, I दबाएं।
  • इससे वर्तमान निष्पादन तुरंत रुक जाता है और KeyboardInterrupt अपवाद (Exception) दिखता है। आपके पहले से बने वैरिएबल्स सुरक्षित रहते हैं।

7.4 Restart Kernel vs Restart & Run All

  • Restart Kernel: यदि कोड में कोई बड़ी गड़बड़ी हो गई हो या मेमोरी फुल हो गई हो, तो कर्नल को रीस्टार्ट किया जाता है। इससे सभी डिक्लेयर्ड वैरिएबल्स और इम्पोर्ट्स मेमोरी से साफ़ हो जाते हैं।
  • Restart & Run All: यह डेटा साइंस में बेस्ट प्रैक्टिस मानी जाती है। अपने प्रोजेक्ट को फाइनल करने से पहले हमेशा Restart & Run All चलाकर देखना चाहिए ताकि यह सुनिश्चित हो सके कि आपका कोड शुरू से अंत तक बिना किसी आउट-ऑफ-ऑर्डर डिपेंडेंसी के सही क्रम में चल रहा है।

Chapter 8: Keyboard Shortcuts (कीबोर्ड शॉर्टकट्स)

अध्याय 8

8.1 Modal Editor Concept (दो मोड्स की अवधारणा)

Jupyter Notebook एक Modal Editor है, ठीक वैसे ही जैसे लोकप्रिय टेक्स्ट एडिटर Vim होता है। इसका मतलब है कि कीबोर्ड की कुंजियाँ इस बात पर निर्भर करती हैं कि आप किस मोड में हैं:

Command Mode
नीला बॉर्डर (Blue Border)
सेल स्तर के ऑपरेशन्स (Delete, Add, Move)
⇋ (Esc / Enter) ⇋
Edit Mode
हरा बॉर्डर (Green Border)
सेल के अंदर टाइपिंग और कोड एडिटिंग
  • Edit Mode (संपादन मोड): जब आप सेल के अंदर टाइप कर रहे होते हैं। सेल का बायां किनारा हरा (Green) होता है। एडिट मोड से बाहर निकलने के लिए Esc दबाएं।
  • Command Mode (कमांड मोड): जब आप सेल के बाहर होते हैं और पूरी नोटबुक को नेविगेट कर रहे होते हैं। सेल का बायां किनारा नीला (Blue) होता है। कमांड मोड से सेल के अंदर जाने के लिए Enter दबाएं।

8.2 Master Shortcuts Cheat Sheet

A. कमांड मोड शॉर्टकट्स (Command Mode - पहले Esc दबाएं):

कुंजी (Key) कार्य (Action) विवरण

B Insert Below वर्तमान सेल के नीचे एक नया सेल जोड़ता है।
D + D (दो बार) Delete Cell वर्तमान सेल को पूरी तरह मिटा देता है।
Z Undo Delete गलती से डिलीट हुए सेल को वापस लाता है (Undo cell deletion)।
Y To Code Cell सेल को Code Cell में बदल देता है।
M To Markdown सेल को Markdown Cell में बदल देता है।

L Toggle Line Numbers सेल में लाइन नंबर्स दिखाना या छुपाना।
H Help / Cheat Sheet सभी उपलब्ध शॉर्टकट्स की पूरी सूची स्क्रीन पर प्रदर्शित करता है।

B. एडिट मोड शॉर्टकट्स (Edit Mode - सेल के अंदर):

कुंजी (Key) कार्य (Action) विवरण
Tab Code Completion कोड ऑटोकम्प्लीट करता है या वैरिएबल/मेथड के सुझाव दिखाता है।
Shift + Tab Docstring Tooltip किसी भी फ़ंक्शन का डॉक्यूमेंटेशन, पैरामीटर्स और सिग्नेचर तुरंत दिखाता है।
Ctrl + / Toggle Comment चुनी हुई लाइन्स पर कमेंट (#) लगाता या हटाता है।
Ctrl + Shift + - Split Cell कर्सर की स्थिति से वर्तमान सेल को दो अलग-अलग सेल्स में विभाजित कर देता है।

Chapter 9: Kernel (कर्नल प्रबंधन)

अध्याय 9

9.1 What is a Kernel? (कर्नल क्या है?)

Kernel जुपिटर नोटबुक का वास्तविक "कम्प्यूटेशनल इंजन" (Computational Engine) है।

  • जब आप किसी सेल में कोड लिखते हैं, तो ब्राउज़र उस कोड को नेटवर्क सॉकेट के माध्यम से कर्नल को भेजता है।
  • कर्नल कोड को निष्पादित करता है, गणना करता है और परिणाम (या त्रुटि/Error) वापस ब्राउज़र को भेजता है जिसे आप आउटपुट के रूप में देखते हैं।
  • पायथन के लिए डिफ़ॉल्ट कर्नल का नाम IPython (ipykernel) है।
⚠️
आउट-ऑफ-ऑर्डर एक्ज़ीक्यूशन ट्रैप (Execution Order Bug):

याद रखें कि कर्नल सेल्स को भौतिक स्थिति (ऊपर से नीचे) के अनुसार याद नहीं रखता, बल्कि आपके चलाने के क्रम के अनुसार याद रखता है। यदि आपने सेल 5 पहले चलाया और सेल 2 बाद में, तो मेमोरी में सेल 5 का प्रभाव पहले दर्ज होगा। In [ ] के अंदर की संख्या ही वास्तविक क्रम बताती है!

9.2 Kernel States (कर्नल की स्थितियाँ)

  • Idle (निष्क्रिय): कर्नल खाली है और नया कोड चलाने के लिए पूरी तरह तैयार है। (ऊपर दाईं ओर खाली वृत्त ⭕)
  • Busy (व्यस्त): कर्नल वर्तमान में कोई गणना कर रहा है। सेल का इनपुट In [*]: दिखेगा और वृत्त भरा हुआ ⚫ होगा।
  • Dead / Disconnected: कर्नल क्रैश हो चुका है। ऐसी स्थिति में जुपिटर ऑटो-रीकनेक्ट करने की कोशिश करता है या आपको रीस्टार्ट का संकेत देता है।

9.3 Kernel Management (कर्नल संचालन)

  • Interrupt: चल रहे भारी लूप या फंक्शन को समाप्त करना बिना मेमोरी खोए।
  • Restart: मेमोरी खाली करके कर्नल को पुनः स्वच्छ स्थिति में शुरू करना।
  • Shutdown: कर्नल को पूरी तरह बंद कर देना ताकि वह सिस्टम की RAM और CPU संसाधनों का उपभोग करना बंद कर दे। डैशबोर्ड के "Running" टैब से ऐसा किया जा सकता है।
  • Change Kernel: यदि आपके पास कई वर्चुअल एनवायरनमेंट्स (Virtual Environments) हैं, तो आप Kernel -> Change Kernel से किसी अन्य एनवायरनमेंट में स्विच कर सकते हैं।

9.4 Virtual Environment को Jupyter Kernel में जोड़ना

यदि आपने conda या venv में कोई अलग वातावरण बनाया है, तो उसे जुपिटर में कर्नल के रूप में पंजीकृत करने का तरीका:

# अपने वर्चुअल एनवायरनमेंट को सक्रिय करें
conda activate my_env
# अथवा: source my_env/bin/activate (Linux/Mac) या my_env\Scripts\activate (Windows)

# ipykernel इंस्टॉल करें
pip install ipykernel

# एनवायरनमेंट को जुपिटर में कर्नल के रूप में जोड़ें
python -m ipykernel install --user --name=my_env --display-name="Python (My ML Env)"

अब जुपिटर में Kernel -> Change Kernel में "Python (My ML Env)" दिखाई देने लगेगा!

अध्याय 10

10.1 The .ipynb File Format (IPython Notebook प्रारूप)

जब आप जुपिटर में कोई नोटबुक सेव करते हैं, तो वह .ipynb एक्सटेंशन के साथ सेव होती है। आंतरिक रूप से यह एक शुद्ध JSON (JavaScript Object Notation) टेक्स्ट फ़ाइल होती है। इसमें निम्नलिखित मुख्य भाग होते हैं:

  • metadata: कर्नल की जानकारी, पायथन वर्ज़न और ऑथर डिटेल्स।
  • cells: एक ऐरे (Array) जिसमें प्रत्येक सेल का प्रकार (code, markdown), सेल का सोर्स कोड, इनपुट क्रम और आउटपुट्स (टेक्स्ट, बेस64 इमेज, एरर ट्रेसबैक) शामिल होते हैं।
  • nbformat: नोटबुक का स्कीमा वर्ज़न (उदा. nbformat: 4)।
// .ipynb फ़ाइल की आंतरिक JSON संरचना का एक नमूना
{
 "cells": [
  {
   "cell_type": "code",
   "execution_count": 1,
   "metadata": {},
   "outputs": [
    {
     "name": "stdout",
     "output_type": "stream",
     "text": [ "Hello, Jupyter!\n" ]
    }
   ],
   "source": [ "print('Hello, Jupyter!')" ]
  }
 ],
 "metadata": {
  "language_info": { "name": "python", "version": "3.11.0" }
 },
 "nbformat": 4,
 "nbformat_minor": 5
}

10.2 Comparison of Export Formats (.ipynb, .py, .html, .pdf, .md)

Jupyter Notebook आपको विभिन्न प्रारूपों में अपनी फ़ाइलों को निर्यात और प्रबंधित करने की सुविधा देता है:

फ़ाइल प्रारूप विवरण व संरचना मुख्य उपयोगिता (Primary Use-Case)
.ipynb डिफ़ॉल्ट JSON-आधारित इंटरैक्टिव नोटबुक फ़ाइल। कोड, आउटपुट, चार्ट्स और नोट्स को एक साथ सहेजने और साथी डेटा साइंटिस्ट्स के साथ शेयर करने के लिए।
.py शुद्ध पायथन स्क्रिप्ट। सभी मार्कडाउन सेल्स को कमेंट (#) में बदल दिया जाता है। प्रोडक्शन पाइपलाइन, ऑटोमेशन स्क्रिप्ट्स, और GitHub पर वर्ज़न कंट्रोल (Git diff) के लिए।
.html स्टैंडअलोन वेबपेज जिसमें CSS और इनलाइन बेस64 चार्ट्स एम्बेड होते हैं। प्रबंधकों, क्लाइंट्स या गैर-तकनीकी टीम के साथ रिपोर्ट्स साझा करने के लिए (जिन्हें पायथन इंस्टॉल करने की आवश्यकता नहीं होती)।
.pdf प्रिंट-रेडी डॉक्युमेंट (LaTeX या हेडलैस ब्राउज़र द्वारा जनरेटेड)। अकादमिक रिसर्च पेपर्स, असाइनमेंट सबमिशन और औपचारिक दस्तावेज़ीकरण।
.md मार्कडाउन टेक्स्ट फ़ाइल। कोड को कोड-ब्लॉक (```python ... ```) के रूप में रखा जाता है। GitHub रिपॉजिटरी के README.md, तकनीकी ब्लॉग्स और विकी पेजेस के निर्माण के लिए।

10.3 Best Practices for Jupyter File Management (सर्वश्रेष्ठ कार्यप्रणाली)

  1. अर्थपूर्ण नामकरण (Meaningful Naming): कभी भी फ़ाइल को Untitled.ipynb या test.ipynb के रूप में न छोड़ें। प्रोजेक्ट और क्रम के अनुसार नाम दें, जैसे: 
    01_data_ingestion.ipynb
02_exploratory_data_analysis.ipynb
03_feature_engineering.ipynb
04_model_training_and_evaluation.ipynb
  2. Clear Outputs Before Git Commit: यदि आप Git का उपयोग करते हैं, तो कमिट करने से पहले Cell -> All Output -> Clear कर लें। इससे गिट रिपॉजिटरी में भारी बाइनरी इमेज नहीं भरतीं और Git Diff साफ़ दिखाई देता है।
  3. .gitignore कॉन्फ़िगरेशन: अपनी गिट रिपॉजिटरी में चेकपॉइंट फ़ोल्डर को अवश्य अनदेखा (Ignore) करें: 
    .ipynb_checkpoints/
__pycache__/
*.pyc
