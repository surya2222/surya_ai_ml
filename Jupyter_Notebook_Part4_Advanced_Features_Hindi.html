Chapter 32: Magic Commands (मैजिक कमांड्स)

अध्याय 32

Magic Commands IPython कर्नेल द्वारा प्रदान किए गए विशेष अंतर्निहित (Built-in) कमांड्स हैं, जो सामान्य पायथन सिंटैक्स के बाहर सिस्टम-स्तरीय कार्य, टाइमिंग और एनवायरनमेंट कंट्रोल की सुविधा देते हैं।

मैजिक कमांड्स दो प्रकार के होते हैं:

  • Line Magics (%): केवल एक एकल पंक्ति पर कार्य करते हैं (जैसे %time, %who)।
  • Cell Magics (%%): पूरे कोड सेल पर कार्य करते हैं और हमेशा सेल की पहली पंक्ति में लिखे जाने चाहिए (जैसे %%timeit, %%writefile)।

32.1 Timing Code Execution: `%time` vs `%timeit`

कमांड कार्यप्रणाली (Mechanism) सर्वश्रेष्ठ उपयोग
%time कोड स्टेटमेंट को केवल एक बार चलाता है और कुल वॉल टाइम (Wall clock time) व CPU टाइम मापता है। भारी ऑपरेशन्स, API कॉल्स, या डेटा लोड करने में लगने वाला वास्तविक समय देखने के लिए।
%timeit कोड को कई बार (जैसे 7 राउंड्स, 10,000 लूप्स) चलाता है और उसका सांख्यिकीय औसत एवं मानक विचलन (Mean ± Std Dev) निकालता है। एल्गोरिदम और माइक्रो-बेंचमार्किंग (कोड ऑप्टिमाइज़ेशन) की सटीक तुलना के लिए।
In [1]:
# %timeit द्वारा लिस्ट बनाम कंप्रिहेंशन की गति मापना %timeit [x**2 for x in range(1000)]
42.8 µs ± 1.12 µs per loop (mean ± std. dev. of 7 runs, 10,000 loops each)

32.2 Running External Scripts: `%run`

बाहरी पायथन स्क्रिप्ट (उदा. data_prep.py) को सीधे नोटबुक के अंदर चलाने के लिए %run का उपयोग किया जाता है। स्क्रिप्ट के चलने के बाद उसके सभी फंक्शन्स और वैरिएबल्स आपकी नोटबुक की मेमोरी में उपलब्ध हो जाते हैं:

%run helper_script.py

32.3 Inspecting Active Variables: `%who` and `%whos`

  • %who: वर्तमान में मेमोरी में मौजूद सभी वैरिएबल्स के नाम प्रदर्शित करता है। (आप %who int या %who DataFrame देकर फ़िल्टर भी कर सकते हैं)।
  • %whos: वैरिएबल्स का एक इंटरैक्टिव टेबल दिखाता है जिसमें उनका नाम, प्रकार, मेमोरी साइज और मान/शेप शामिल होते हैं।
  • %reset: कर्नेल को रीस्टार्ट किए बिना मेमोरी से सभी वैरिएबल्स को एक साथ डिलीट करता है।
In [2]:
a = 500 b = "Data Science" c = [1, 2, 3, 4] %whos
Variable Type Data/Info ----------------------------- a int 500 b str Data Science c list n=4

32.4 Other Essential Magics

  • %%writefile filename.py: सेल के पूरे कोड को डिस्क पर फ़ाइल के रूप में सहेजता है।
  • %lsmagic: सिस्टम में उपलब्ध सभी लाइन और सेल मैजिक्स की सूची प्रदर्शित करता है।
  • %env: ऑपरेटिंग सिस्टम के एनवायरनमेंट वैरिएबल्स देखना व सेट करना।

Chapter 33: Shell Commands (शेल कमांड्स / CLI Integration)

अध्याय 33

Jupyter Notebook आपको सेल के अंदर से ही आपके ऑपरेटिंग सिस्टम के टर्मिनल / कमांड प्रॉम्प्ट (CLI) को सीधे निष्पादित करने की सुविधा देता है। इसके लिए कमांड के आगे विस्मयादिबोधक चिन्ह (!) लगाया जाता है।

33.1 Package Installation inside Notebook (`!pip` vs `%pip`)

लाइब्रेरी इंस्टॉल करने के लिए !pip install का उपयोग बहुत आम है, लेकिन आधुनिक IPython में %pip मैजिक को अनुशंसित किया जाता है:

कमांड व्यवहार (Behavior) सिफारिश (Recommendation)
!pip install pandas सिस्टम के डिफ़ॉल्ट शेल में pip चलाता है। यदि कई पायथन वर्ज़न हों, तो यह गलत एनवायरनमेंट में पैकेज इंस्टॉल कर सकता है। सामान्य उपयोग, पर एनवायरनमेंट मिसमैच का जोखिम।
%pip install pandas वर्तमान में चल रहे कर्नेल के सही एनवायरनमेंट को पहचान कर उसी में पैकेज इंस्टॉल करता है। सर्वश्रेष्ठ अभ्यास (Recommended Standard)

33.2 File System Navigation (`!dir`, `!ls` और `%cd`)

  • Windows में फ़ाइलों की सूची: !dir
  • Linux/Mac में फ़ाइलों की सूची: !ls -la
  • डायरेक्टरी बदलने का नियम: !cd my_folder काम नहीं करता क्योंकि ! एक अस्थायी सबशेल में चलता है जो समाप्त होते ही मूल फ़ोल्डर में लौट आता है। डायरेक्टरी बदलने के लिए हमेशा मैजिक कमांड %cd my_folder का प्रयोग करें।

33.3 Capturing Shell Output in Python Variables

शेल कमांड के आउटपुट को आप सीधे पायथन वैरिएबल में स्टोर कर सकते हैं और पायथन वैरिएबल को शेल कमांड में पास कर सकते हैं:

In [3]:
# 1. शेल आउटपुट को पायथन लिस्ट में कैप्चर करना files = !dir /b *.ipynb # 2. पायथन वैरिएबल को शेल कमांड में कर्ली ब्रेसिस {} द्वारा पास करना target_file = "sample.txt" !echo "नमस्ते दुनिया" > {target_file} print("खोजी गई नोटबुक्स:", files)
खोजी गई नोटबुक्स: ['01_basics.ipynb', '02_eda.ipynb']

Chapter 34: IPython (इंटरैक्टिव निष्पादन एवं विशेषताएं)

अध्याय 34

34.1 Dynamic Object Introspection (`?` और `??`)

IPython कोड के आंतरिक घटकों को बिना किसी बाहरी डॉक्यूमेंटेशन के तुरंत जांचने की सुविधा देता है:

  • object? (त्वरित सहायता): किसी भी फ़ंक्शन या क्लास के नाम के आगे ? लगाकर रन करने पर उसका सिग्नेचर और Docstring खुल जाती है।
  • object?? (सोर्स कोड): यदि ऑब्जेक्ट शुद्ध पायथन में लिखा गया है, तो ?? लगाने पर उस फ़ंक्शन का वास्तविक स्रोत कोड (Source Code) सीधे सेल में दिख जाता है!
In [4]:
import math # math.sqrt फ़ंक्शन का सोर्स/डॉक्यूमेंटेशन देखना math.sqrt?
Docstring: sqrt(x, /) Return the square root of x. Type: builtin_function_or_method

34.2 Input and Output History (`In`, `Out`, `_`)

IPython सभी इनपुट्स और आउटपुट्स का पूरा इतिहास मेमोरी में सुरक्षित रखता है:

  • _ (सिंगल अंडरस्कोर): ठीक पिछले सेल का अंतिम आउटपुट मान।
  • __ (डबल अंडरस्कोर): पिछले से पिछले सेल का आउटपुट।
  • Out[5]: सेल नंबर 5 का आउटपुट मान।
  • In[5]: सेल नंबर 5 में लिखा गया इनपुट कोड (स्ट्रिंग के रूप में)।
  • आउटपुट छिपाना: लाइन के अंत में सेमीकोलन (;) लगाने से सेल का टेक्स्ट आउटपुट (जैसे <AxesSubplot:...>) स्क्रीन पर प्रिंट नहीं होता।

Chapter 35: Display Functions (`IPython.display`)

अध्याय 35

35.1 Why `display()` is Superior to `print()`

साधारण print() फ़ंक्शन किसी भी ऑब्जेक्ट को केवल सादे टेक्स्ट (String) में बदल देता है। इसके विपरीत, IPython.display.display() ऑब्जेक्ट के सबसे समृद्ध MIME प्रकार (Rich MIME Representation) को रेंडर करता है (जैसे सुंदर स्टाइल्ड HTML टेबल, इंटरेक्टिव प्लॉट्स, और ग्राफिक्स)।

In [5]:
import pandas as pd from IPython.display import display df = pd.DataFrame({'नाम': ['सोनू', 'मोनू'], 'अंक': [95, 88]}) # एक ही सेल में कई डेटाफ्रेम्स को उनके सुंदर HTML ग्रिड में प्रदर्शित करना display(df) display(df.describe())
[Pandas DataFrame सुंदर HTML टेबल के रूप में रेंडर होगा]

35.2 `HTML()`, `Markdown()`, and `Latex()`

पायथन कोड के अंदर से सीधे वेब एलिमेंट्स और डायनेमिक गणितीय समीकरण रेंडर किए जा सकते हैं:

In [6]:
from IPython.display import HTML, Markdown, Latex total_records = 50000 # डायनेमिक मार्कडाउन रेंडरिंग display(Markdown(f"### कुल प्रोसेस हुए रिकॉर्ड्स: **{total_records:,}**")) # कस्टम HTML बैनर display(HTML("<div style='padding:10px; background:#dcfce7; border-radius:6px; color:#166534;'>✔ डेटा सफलतापूर्वक सत्यापित हुआ!</div>"))
### कुल प्रोसेस हुए रिकॉर्ड्स: 50,000 ✔ डेटा सफलतापूर्वक सत्यापित हुआ!

35.3 `clear_output(wait=True)`: Real-Time Dynamic Progress

मशीन लर्निंग मॉडल ट्रेनिंग या भारी लूप के दौरान हर बार नई लाइन प्रिंट करके स्क्रीन भरने के बजाय, clear_output(wait=True) आउटपुट को उसी जगह फ्लैश (Update in-place) करता है:

from IPython.display import clear_output
import time

for epoch in range(1, 6):
    clear_output(wait=True)
    print(f"प्रगति: Epoch {epoch}/5 पूरा हुआ...")
    time.sleep(0.5)

Chapter 37: Widgets (`ipywidgets` - GUI इनपुट कंट्रोल्स)

अध्याय 37

ipywidgets जुपिटर नोटबुक को एक इंटरैक्टिव डैशबोर्ड में बदल देता है। इसके माध्यम से उपयोगकर्ता बिना कोड बदले केवल स्लाइडर्स, ड्रॉपडाउन और बटन्स को हिलाकर पायथन कोड को लाइव इनपुट दे सकते हैं।

37.1 Installation

%pip install ipywidgets

37.2 The `@interact` Magic Decorator

@interact डेकोरेटर किसी भी पायथन फ़ंक्शन के पैरामीटर्स को देखकर स्वचालित रूप से उपयुक्त GUI विजेट तैयार कर देता है:

In [7]:
from ipywidgets import interact # फ़ंक्शन के इनपुट के आधार पर स्लाइडर और चेकबॉक्स अपने आप बन जाएंगे @interact(x=(1, 100, 5), show_details=True) def analyze_data(x=25, show_details=True): print(f"चुनी गई संख्या का वर्ग: {x**2}") if show_details: print(f"दोगुना मान: {x*2} | घन: {x**3}")
[एक लाइव इंटरैक्टिव स्लाइडर (1 से 100) और चेकबॉक्स यहाँ प्रदर्शित होगा]

37.3 Common Dedicated Widgets: Sliders, Buttons & Dropdowns

import ipywidgets as widgets
from IPython.display import display

# ड्रॉपडाउन विजेट
dropdown = widgets.Dropdown(
    options=['LinearRegression', 'RandomForest', 'XGBoost'],
    value='RandomForest',
    description='मॉडल चुनें:'
)

# बटन विजेट
button = widgets.Button(description="मॉडल ट्रेन करें 🚀", button_style='success')

def on_click_train(b):
    print(f">> {dropdown.value} का प्रशिक्षण प्रारंभ हुआ...")

button.on_click(on_click_train)

# दोनों को एक साथ क्षैतिज रूप (HBox) में दिखाना
display(widgets.HBox([dropdown, button]))

Chapter 39: Multiple Kernels (बहु-भाषाई कर्नल्स)

39.1 Language-Agnostic Architecture

Jupyter Notebook केवल पायथन के लिए नहीं है! इसका आर्किटेक्चर क्लाइंट (वेब ब्राउज़र) और सर्वर (कर्नल) के बीच ZeroMQ नेटवर्क सॉकेट्स पर आधारित है। इसका अर्थ है कि बैकएंड इंजन को किसी भी प्रोग्रामिंग भाषा से बदला जा सकता है:

भाषा (Language) कर्नल का नाम स्थापना एवं उपयोग
Python ipykernel डिफ़ॉल्ट रूप से स्थापित (Python 3)।
R IRkernel R कंसोल में: install.packages('IRkernel'); IRkernel::installspec()
Julia IJulia जूलिया में: using Pkg; Pkg.add("IJulia")
C++ xeus-cling C++ 14/17 इंटरैक्टिव कोड निष्पादन के लिए।
Bash / SQL bash_kernel, xeus-sql डेटाबेस एडमिनिस्ट्रेशन और लिनक्स स्क्रिप्ट्स सीधे चलाने के लिए।

Chapter 42: Debugging Tools (%debug, Breakpoints)

अध्याय 42

42.1 Post-Mortem Debugging with `%debug`

जब भी कोई सेल अप्रत्याशित रूप से क्रैश हो जाए (Exception Traceback आए), तो ठीक नीचे एक नया सेल बनाकर %debug चलाएं।

  • यह आपको त्रुटि के सटीक क्षण पर ले जाता है।
  • वहाँ आप वैरिएबल्स के मान प्रिंट (p var_name) कर सकते हैं और स्टैक फ्रेम ऊपर/नीचे (u/d) घूम सकते हैं।

42.2 Python's Built-in `breakpoint()`

Python 3.7+ में आप कोड के किसी भी हिस्से में सीधे breakpoint() लिख सकते हैं। जैसे ही सेल रन होगा, वह उसी लाइन पर रुक जाएगा और इंटरैक्टिव PDB कंसोल खोल देगा:

def compute_discount(price, discount_percent):
    if discount_percent > 100:
        breakpoint()  # यहाँ कोड रुक जाएगा और डीबगर शुरू होगा
    return price * (1 - discount_percent/100)

42.3 Visual Breakpoints in Modern Jupyter

JupyterLab और आधुनिक Jupyter Notebook 7 में ऊपर दाईं ओर एक कीड़ा (Bug Icon 🐞) होता है। इसे चालू करने पर आप कोड एडिटर में लाइन नंबर पर क्लिक करके लाल बिंदु (Visual Breakpoint) लगा सकते हैं और वेरिएबल ट्री को लाइव देख सकते हैं।

43.2 Memory Profiling: `%memit` and Garbage Collection

डेटा साइंस में बड़े डेटासेट्स (लाखों पंक्तियाँ) लोड करने पर अक्सर MemoryError आता है। मेमोरी अनुकूलन के सर्वोत्तम नियम:

  1. Garbage Collection: बड़े वैरिएबल का काम खत्म होते ही del df_large करें और import gc; gc.collect() चलाकर RAM को तुरंत मुक्त करें।
  2. Downcasting DataTypes: Pandas में डिफ़ॉल्ट int64 या float64 को int32, float32 या टेक्स्ट को category में बदलकर मेमोरी को 70% तक घटाया जा सकता है: 
    df['category_col'] = df['category_col'].astype('category')

Chapter 44: Parallel Computing & Concurrency (समानांतर कंप्यूटिंग)

अध्याय 44

पायथन में GIL (Global Interpreter Lock) के कारण सामान्य कोड केवल एक ही CPU कोर का उपयोग करता है। आधुनिक मल्टी-कोर प्रोसेसर्स (उदा. 8-core या 16-core) की पूरी क्षमता का उपयोग करने के लिए समानांतर कंप्यूटिंग तकनीकों का उपयोग किया जाता है।

44.1 `concurrent.futures` (Threading vs Multiprocessing)

  • ThreadPoolExecutor (I/O-Bound Tasks): जब आपका कोड वेब API कॉल्स, फ़ाइल डाउनलोड या नेटवर्क रिक्वेस्ट्स में अटका रहता है।
  • ProcessPoolExecutor (CPU-Bound Tasks): जब आपको भारी गणितीय गणनाएं, इमेज प्रोसेसिंग या मशीन लर्निंग मॉडल्स को कई CPU कोरों पर एक साथ चलाना हो।
In [9]:
from concurrent.futures import ProcessPoolExecutor import time def heavy_computation(n): return sum(i * i for i in range(n)) inputs = [10_000_000, 10_000_000, 10_000_000, 10_000_000] # सभी उपलब्ध CPU कोरों पर समानांतर गणना start = time.time() with ProcessPoolExecutor() as executor: results = list(executor.map(heavy_computation, inputs)) print(f"परिणाम: {len(results)} गणनाएं पूरी हुईं | कुल समय: {time.time() - start:.2f}s")
परिणाम: 4 गणनाएं पूरी हुईं | कुल समय: 0.85s (सिंगल कोर पर यह ~3.2s लेता!)

44.2 Parallel Computing with `joblib`

Scikit-Learn और डेटा साइंस में joblib सबसे लोकप्रिय और सरल टूल है:

from joblib import Parallel, delayed

# n_jobs=-1 का अर्थ है कंप्यूटर के सभी CPU कोरों का उपयोग करें
results = Parallel(n_jobs=-1)(delayed(heavy_computation)(x) for x in inputs)

44.3 High-Performance Tools: `ipyparallel` and `Dask`

  • IPython Parallel (ipyparallel): नोटबुक को कई मशीनों (Cluster nodes) पर डिस्ट्रीब्यूटेड रूप से चलाने के लिए।
  • Dask: बड़े डेटासेट्स जो RAM से बड़े होते हैं (Out-of-Core Processing), उन्हें Pandas जैसी सिंटैक्स में स्वचालित रूप से समानांतर रूप से प्रोसेस करता है।
